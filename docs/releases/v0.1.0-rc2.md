## Release Decision

Prepare `v0.1.0-rc2`, but do not promote a stable release yet.

Public release state checked with GitHub CLI on 2026-06-25:

- `gh release list --repo 0boluan0/Chronicle --limit 5` still marks `v0.1.0-rc1` as the latest release.
- `gh release view v0.1.0-rc1 --repo 0boluan0/Chronicle --json tagName,isDraft,isPrerelease,publishedAt,name,assets,url` confirms the published release is not a draft, includes the DMG and `.sha256` assets, and was published at `2026-04-26T10:58:45Z`.
- The published `Chronicle-v0.1.0-rc1.dmg` asset reports `sha256:21d9e4d067d8b27318414005e9664b0cc17ca749163b003e6d91460855bfd698`.
- Local development has moved 436 commits past `v0.1.0-rc1`.
- The current app marketing version remains `0.1.0`, build `7`.

This is enough product movement to justify a new RC once the release gates pass. It is not enough to publish a stable release directly, because the full upgrade, rollback, export, clean-install, and artifact checks have not all been completed for this candidate.

## Candidate Scope

This RC should summarize the accumulated product polish since `v0.1.0-rc1`:

- Adds the daily command center flow across the menu bar popover, dashboard, reports, and quick marker surfaces.
- Connects overview, weekly lane, work-block, and top-category summaries into filtered Timeline drill-downs.
- Shares daily export progress and failure state across entry points so the app reports one consistent status.
- Expands App Health, support readiness, post-update checks, diagnostics, and release safety surfaces.
- Improves onboarding, privacy reversibility, window-title handling, capture setup, and preferences guidance.
- Polishes refresh, busy, stale-result, empty-state, and retry feedback across dashboard, reports, preferences, popover, and marker views.
- Adds Reports setup readiness cues in the Dashboard sidebar and Reports workspace header so export blockers are visible before saving.
- Strengthens localization key parity, duplicate-key preflight checks, and UI smoke coverage for newly exposed user-facing copy.
- Hardens release workflow, checksum documentation, and UI-smoke automation guardrails.
- Switches the macOS candidate to an unsandboxed runtime for direct local tracking/export workflows, with migration from the previous sandbox container when local data exists.
- Centralizes system folder selection and window sizing metrics so Reports, onboarding, popover, preferences, dashboard, and quick marker surfaces behave consistently at smaller window sizes.
- Splits idle runtime status updates from high-frequency idle samples to reduce unnecessary view invalidation while preserving live idle diagnostics.
- Refines the Reports closeout and preview surfaces with more resilient narrow-window text wrapping for daily closeout steps, save-confidence cards, reminder outcomes, and preview check cards.
- Adds clearer Review Reminder scheduling feedback so users can see whether reminders are off, menubar-only, or menubar plus local notification before relying on them.
- Removes stale rc1-specific release command examples from the stable release checklist and asset verification helper.
- Allows Dashboard sidebar navigation titles to wrap cleanly in narrow columns and localized builds.
- Allows App Categories review path and impact cards to wrap cleanly in narrow columns and localized builds.
- Allows Tags and Rules starter-preview and rule metric cards to wrap cleanly in narrow columns and localized builds.
- Allows App Health detail labels, next-step copy, and technical detail labels to wrap cleanly in narrow support windows.
- Adds a release preflight guard that catches stale Draft RC commit-distance notes before a candidate is published.
- Allows Insights top app and category rows to wrap names and summaries cleanly in narrow columns.
- Allows Support technical information rows to wrap long version, bundle, and local path values while preserving text selection.
- Allows Onboarding focus, positioning, and first-day labels to wrap cleanly in narrow first-run windows.
- Polishes the Dashboard sidebar next-step card with an inline status pill, consolidated readiness progress, and a steadier full-width primary action.
- Polishes the Markers next-step card with an inline capture status, consolidated progress, and steadier full-width action buttons.

## Release Gates Still Required

Before publishing `v0.1.0-rc2`:

- Freeze the release branch and target tag.
- Run `./script/run_release_preflight.sh` from a clean source state.
- Run Debug unit tests for `Chronicle`.
- Run bilingual UI smoke with `./script/run_ui_smoke.sh all`.
- Run the fuller public-beta smoke scope with `./script/run_ui_smoke.sh full` before promoting the RC, including the Reports system folder picker sheet path.
- Verify no unplanned schema migration is included.
- Test upgrade from the previous public release to the candidate.
- Test rollback by backing up the user database and relaunching the previous public build.
- Verify daily Markdown export, weekly Markdown export, CSV export, timezone boundaries, and export bookmark recovery.
- Build the DMG with the RC artifact version and verify the generated checksum.
- Verify the GitHub Release asset digest, uploaded `.sha256` asset, README download copy, and this release note all name the same artifact checksum.
- Run `bash script/check_release_assets.sh v0.1.0-rc2` after upload and before promotion.
- Smoke-test install on a clean macOS user account.

## Known Limitations

- No distribution signing or notarization credentials are currently assumed. Without those credentials, the RC remains a development/notarization-free candidate.
- Local `dist/` output is not public release evidence until it is attached to GitHub Releases and re-verified there.
- UI smoke requires a dedicated macOS runner with Automation Mode enabled without per-run authentication.

## Publish Trigger

Publish `v0.1.0-rc2` when the release gates above pass, the DMG and checksum are verified, and the public GitHub Release assets match the documented checksum.

Promote a stable release only after this RC has clean install, upgrade, rollback, export, localization, and first-run smoke evidence with no release-blocking defects.
