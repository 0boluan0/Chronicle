# Chronicle v0.1.0-rc3 Release Candidate

Date: 2026-06-26
App version: `0.1.0`
Build: `7`

Status: Published GitHub prerelease

## Release Decision

Published `v0.1.0-rc3` as a small GitHub prerelease so the app's update and support links point users at the full Releases page, where prerelease DMGs are visible.

This is not a stable release. Signing, notarization, clean-install, upgrade, rollback, and full export smoke evidence are still required before stable promotion.

GitHub prerelease: `https://github.com/0boluan0/Chronicle/releases/tag/v0.1.0-rc3`

## Candidate Scope

- Points Support and Update Trust actions at the GitHub Releases page instead of `/releases/latest`, because GitHub does not allow prereleases to be marked as Latest.
- Renames the visible update actions from "Open Latest Release" to "Open Releases Page" in English and Simplified Chinese.
- Updates the copied update checklist to send testers to the full Releases page.
- Refreshes README download links, release badge target, artifact names, size, checksum, and validation commands for `v0.1.0-rc3`.
