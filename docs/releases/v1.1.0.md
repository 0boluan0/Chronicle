# Chronicle v1.1.0

Date: 2026-07-10
App version: `1.1.0`
Build: `8`
Artifact tag/version: `v1.1.0`

## Highlights

- Closes the active tracking session before quit so the final work interval is not lost.
- Preserves live window-title context for privacy filtering and tag rules.
- Makes database initialization and schema migration fail closed instead of continuing with a partial schema.
- Migrates legacy SQLite databases through the backup API so committed WAL data is preserved.
- Removes aggregation and report-generation data races covered by concurrent regression tests.
- Prevents spreadsheet formula execution when exported CSV files are opened.
- Isolates UI automation preferences and app data from a user's live Chronicle installation.
- Simplifies first-run, Today, Timeline, and Daily Log surfaces and completes the Simplified Chinese app-filter translation.

## Data and Upgrade Behavior

- Continues the existing public version line from `v1.0.5` (build `6`) to `v1.1.0` (build `8`).
- Existing local activity, notes, tags, rules, and export settings remain in place.
- The sandbox-to-Application-Support database move is transactional: a failed copy does not replace the destination database.
- Window-title schema migration retains rule tags, manual overrides, and effective tags.
- Downgrading the database in place is not supported. Quit Chronicle and restore a pre-upgrade database backup before reinstalling an older build.

## Validation

- Release preflight, localized string parity, and workflow syntax checks.
- 64 unit tests covering tracking, migrations, aggregation, end-to-end report exports, privacy, and CSV safety.
- Full English and Simplified Chinese UI smoke suite on an isolated test workspace.
- Signed and notarized DMG verification, stapling validation, checksum verification, and uploaded-asset verification are enforced by the release workflow.

## Known Limitations

- Updates remain manual through GitHub Releases; Chronicle does not run a background updater.
- Window-title capture remains opt-in and requires macOS Accessibility permission.
